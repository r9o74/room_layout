# 研究室レイアウトシミュレータ

研究室の家具配置を、上から見た図でシミュレーションするWebアプリです。ビルド不要で、`index.html` をブラウザで開くだけで動きます。

## 機能

- 画面左 2/3 に部屋を真上から見た図を表示
- 家具をドラッグして移動 (5cm単位でスナップ)
- 家具は重なる位置に置けない。**先に置かれていた家具が優先**され、後から動かす側が止まる (壁沿い・他の家具沿いには滑る)
- 画面右 1/3 で家具を追加: 名称・幅・奥行・色を入力するとプレビューを表示。机や椅子などのプリセットもあり
- 選択した家具の 90° 回転 (`R`) と削除 (`Delete`)
- 部屋サイズの変更 (cm単位)
- 配置はブラウザの localStorage に自動保存

## 使い方

```sh
open index.html
```

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `style.css` | レイアウト・見た目 |
| `app.js` | 描画・ドラッグ・衝突判定・保存 |
