# 研究室レイアウト

研究室の家具配置を、上から見た図でシミュレーションするWebアプリです。ビルド不要で、`index.html` をブラウザで開くだけで動きます。

## 機能

- 画面左 2/3 に部屋 (660×480cm、固定) を真上から見た図を表示。方眼は 10cm、太線は 1m
- 家具をドラッグして移動 (5cm単位でスナップ)。矢印キーで 10cm、Shift+矢印で 50cm 移動
- 家具は重なる位置に置けない。**先に置かれていた家具が優先**され、後から動かす側が止まる (壁沿い・他の家具沿いには滑る)。ぶつかった家具は赤く光る
- 画面右 1/3 で家具を追加: 名称・幅・奥行・色 (6色) を入力すると、人の大きさと並べたプレビューを表示。よく使う家具のプリセットもあり
- 家具をクリックすると近くにメニューを表示: 左・右回転、サイズ変更、複製、色の変更
- 複数選択: Shift+クリック、または空白部分からドラッグして範囲選択 (Ctrl/⌘+A で全選択)
  - 選択した家具をまとめて移動・複製・回転 (右 `R` / 左 `Shift+R`) できる。回転はグループ全体を1つの塊として90°回す
- 配置はブラウザの localStorage に自動保存

## テンプレート

柱・シンク・傘立て・エントランス・靴箱・ホワイトボードは、初期配置のテンプレートとして固定されています。
移動・回転・複製・サイズ変更・削除はできず、色の変更のみ可能です (範囲選択では選ばれません)。
「すべて削除」を2回押すと、追加した家具を消してテンプレートの配置 (色も初期色) に戻ります。

テンプレートの内容は `app.js` の `TEMPLATE` 配列、部屋のサイズは `ROOM` で編集できます。

## 使い方

```sh
open index.html
```

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `style.css` | レイアウト・見た目 (ライト/ダークモード対応) |
| `app.js` | 描画・ドラッグ・衝突判定・保存 |
