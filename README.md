# 研究室レイアウト

研究室の家具配置を、上から見た図でシミュレーションするWebアプリです。ビルド不要で、`index.html` をブラウザで開くだけで動きます。

## 機能

- 画面左 2/3 に部屋 (660×480cm、固定) を真上から見た図を表示。方眼は 10cm、太線は 1m
- 家具をドラッグして移動 (5cm単位でスナップ)。矢印キーで 10cm、Shift+矢印で 50cm 移動
- 家具は重なる位置に置けない。**先に置かれていた家具が優先**され、後から動かす側が止まる (壁沿い・他の家具沿いには滑る)。ぶつかった家具は赤く光る
- 画面右 1/3 で家具を追加: 名称・形状・サイズ・色 (6色) を入力すると、人の大きさと並べたプレビューを表示。よく使う家具のプリセットもあり
  - 形状は四角 (初期値)・丸・三角から選ぶ。四角は幅×奥行、丸は半径、三角 (直角三角形のみ) は直角をはさむ2辺の長さを入力する
  - 重なり判定は図形どおりに行うので、三角の斜辺側に別の家具を寄せたり、三角2つを合わせて四角にしたりできる。三角の直角の向きは回転 (右・左) で変える。丸は回転できない
- 家具の名称は空欄でもよい。名称のない家具は、レイアウト・プレビューには名前を出さず (サイズだけ表示)、「配置中の家具」の一覧では `-` と表示する
- 家具をクリックすると近くにメニューを表示: 左・右回転、サイズ変更、複製、名称変更、色の変更
  - サイズ変更の **MAX**: 幅・奥行それぞれの入力欄の下にある。押すと、その方向の両側へ他の家具や壁に当たるまで広げる (位置はその方向に動くことがある)。丸は中心を保ったまま半径を広げる
- **敷物**: 家具の追加フォームの色の行 (右端) と、色の変更パネルにスイッチがある (初期値はオフ)。オンの家具は敷物でない家具と重ねて置け、他の家具より背面に描かれる。見た目は変わらず、敷物の上の家具は透けずに家具だけが見える。敷物どうしは重ねられない。スイッチを切り替えた結果が重なりになる場合は切り替えられない
- 複数選択: Shift+クリック、または空白部分からドラッグして範囲選択 (Ctrl/⌘+A で全選択)
  - 選択した家具をまとめて移動・複製・回転 (右 `R` / 左 `Shift+R`) できる。回転はグループ全体を1つの塊として90°回す
  - Ctrl+C (Mac は ⌘+C) でコピー、Ctrl+X で切り取り、Ctrl+V で貼り付け。貼り付けは複製ボタンと同じ置き方になる。切り取った直後の最初の貼り付けだけは、元の位置にそのまま戻る (切り取りも Ctrl+Z で取り消せる)
  - 複製した家具はコピー元のすぐそばに置かれる。複数選択のときは家具どうしの位置関係を保ったまま複製し、全部は置けない場合は置ける分だけ複製する (他の家具と重なるものは複製しない)
- **取り消し・やり直し**: Ctrl+Z (Mac は ⌘+Z) で取り消し、Ctrl+Y (または Ctrl+Shift+Z) でやり直し。家具の追加・移動・回転・サイズ・色・名称・敷物の変更、複製・貼り付け、削除、「すべて削除」が対象で、100回分まで戻れる。別のレイアウトを開く・新規レイアウトにすると履歴は消える。入力欄の中では通常の取り消しになる
- 編集中の配置はブラウザの localStorage に自動保存 (再読み込みしても消えない)

## レイアウトの保存 (Supabase)

- **新規保存**: 名前と作成者 (任意) をつけて保存。名前の初期値は「レイアウト＋通し番号」
- **レイアウト名の変更**: 保存済みのレイアウトを開いているとき、上部のレイアウト名の右にある鉛筆ボタンから変更できる (Enter で確定、Esc でキャンセル)。名前だけが即座に保存され、家具の配置は「更新」を押すまで保存されない。他の人が先に更新していた場合は変更できない
- **更新**: 保存済みのレイアウトを開いて編集しているときだけ使える。他の人が先に更新していた場合は確認してから上書き
- **メニュー**: 全員が保存したレイアウトの一覧を表示。選ぶとプレビューが出て、「続きから編集」または「コピーして編集」(別のレイアウトとして新規保存できる) を選べる。「新しいレイアウトを作成」でテンプレートから始め直せる
- ログインはなく、誰でも閲覧・保存・更新できる (削除はできない)

保存先は Supabase プロジェクト `room_layout` の `public.layouts` テーブルです。接続先と公開キーは `db.js` にあります (公開キーは公開して問題ないもので、操作は RLS で制限しています)。

## テンプレート

柱・シンク・傘立て・エントランス・靴箱・ホワイトボードは、初期配置のテンプレートとして固定されています。
移動・回転・複製・サイズ変更・削除はできず、色の変更のみ可能です (範囲選択では選ばれません)。
「すべて削除」を2回押すと、追加した家具を消してテンプレートの配置 (色も初期色) に戻ります。

テンプレートの内容は `app.js` の `TEMPLATE` 配列、部屋のサイズは `ROOM` で編集できます。

## 使い方

```sh
open index.html
```

## ファイル構成

| ファイル | 内容 |

| `index.html` | 画面の骨組み |
| `style.css` | レイアウト・見た目 |

| `db.js` | Supabase (REST API) との通信 |
